คุณสมบัติหลัก
-3 หมวดหมู่หลัก: ดอกไม้, สัตว์, และสถานที่
-อินเทอร์เฟซแบบ ASCII Art: ใช้ไลบรารี pyfiglet ในการสร้างชื่อเกมที่ดูมีสไตล์ และแสดงภาพ ASCII Art อย่างง่ายของหมวดหมู่เมื่อเริ่มตอบคำถาม
-การแสดงผลมีสีสัน: ใช้ colorama เพื่อทำให้ข้อความมีความโดดเด่นและเข้าใจง่าย (สีเขียวสำหรับคำตอบที่ถูก, สีแดงสำหรับคำตอบที่ผิด, สีน้ำเงินสำหรับคำถาม)
-การติดตามคะแนน: บันทึกคะแนนและจำนวนรอบทั้งหมดที่เล่น เพื่อสรุปผลเมื่อจบเกม

วิธีการรันเกม
1.บันทึกโค้ดของคุณในไฟล์ Python (เช่น quiz_game.py).
2.เปิดหน้าต่าง Command-line (Terminal, Command Prompt, หรือ PowerShell).
3.ไปยังไดเรกทอรีที่บันทึกไฟล์ไว้.
4.รันเกมด้วยคำสั่ง:python quiz_game.py

วิธีการเล่น
1.เกมจะเริ่มต้นด้วยการแสดงหน้าจอ Welcome screen ที่เป็น ASCII Art
2.ระบบจะให้คุณเลือกหมวดหมู่โดยป้อนตัวเลข (1, 2, หรือ 3):
   1. Flower (ดอกไม้)
   2. Animal (สัตว์)
   3. Place (สถานที่)
3.หลังจากเลือกแล้ว จะมีการแสดง ภาพ ASCII Art ของหมวดหมู่นั้น และแสดงคำถามออกมา
4.พิมพ์คำตอบของคุณและกด Enter (คำตอบเป็นแบบ ไม่คำนึงถึงตัวพิมพ์เล็ก/ใหญ่ เช่น "rose" และ "Rose" ถือว่าถูกต้องเหมือนกัน)
5.เกมจะแจ้งผลว่าคำตอบของคุณ ถูกต้อง หรือ ไม่ถูกต้อง พร้อมแสดงคะแนนล่าสุด
6.เมื่อจบแต่ละรอบ ระบบจะถามว่าต้องการเล่นต่อหรือไม่: พิมพ์ Yes เพื่อเล่นต่อ หรือพิมพ์อย่างอื่น (เช่น No) เพื่อจบเกม
7.เมื่อจบเกม หน้าจอ Game Over จะแสดงคะแนนสุดท้ายและจำนวนรอบทั้งหมดที่เล่น
